# Simulaci-n-Num-rica-Olas
En este repostorio se encuentran todos los avances del proyecto de DMD, cuyo objetivo es simular olas de mar utilizando la aproximación de Boussinesq

El repositorio cuenta con 3 notebooks de python, cada uno contiene:

1) Simulación_DMD_Guassiana: El código para simular el comportamiento de una ola con las ecuaciones de Boussinesq para un perfil gaussiano para la superficie libre de la ola y una velocidad contante para la condición inicial.

2) Simulación_DMD_onda_solitaria: El código para simular el comportamiento de un solitón (una ola que se mueve a velocidad contante con amplitud constante y cuyo perfil es proporcional a la sech^2).
   
3) Comprobación_ola: El código donde se realizó el análisis que revela la confiabilidad de la simulación para el regimen de la aproximación de Boussinesq.
